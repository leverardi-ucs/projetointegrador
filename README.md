
# Brick Breaker

Projeto desenvolvido para a disciplina de Projeto Integrador VI-A.

O objetivo do projeto é desenvolver um aplicativo móvel baseado no estilo clássico de jogo Brick Breaker, aplicando os conhecimentos adquiridos nas disciplinas de Dispositivos Móveis I e Fundamentos de IA.

O jogo consiste em controlar uma plataforma para rebater uma bola e destruir os blocos/tijolos presentes na parte superior da tela. O aplicativo contará com diferentes níveis, configurações de aparência dos blocos e progressão entre as fases.
